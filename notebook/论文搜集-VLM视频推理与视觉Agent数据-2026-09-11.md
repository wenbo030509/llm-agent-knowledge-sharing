## 一、2025 主线：诊断视觉短板 → 靶向合成视频推理数据 → SFT/RL

> 这条线和我 vlm-agent 项目**几乎同构**：数据瓶颈诊断 → 多阶段合成 → 反捷径过滤 → SFT 冷启动 → RL + 过程奖励 → 消融归因。

| 论文 | 机构 | 一句话 | 关键数字/设计 | 链接 |
|---|---|---|---|---|
| **ReWatch-R1** ⭐已精读 | Alibaba | 多阶段合成 + 多智能体 ReAct 造视频推理数据 | 10k caption/170k QA/135k CoT；θ_text=θ_sum=1；O&R 过程奖励；Avg 35.51 SOTA | [2509.23652](https://arxiv.org/html/2509.23652v1) |
| **Video-Thinker** | 小红书/东南大 | "边看边想"：SFT 学 grounding/caption 格式 → GRPO 强化 | SFT→GRPO 两阶段；in-domain + OOD 都涨 | [2510.23473](https://arxiv.org/html/2510.23473v1) |
| **Video-R2** | MBZUAI | 用两个诊断指标约束"推理忠实" | TAC（推理-答案一致）+ VAS（靠视觉还是文本）+ Temporal Alignment Reward | [2511.23478](https://arxiv.org/html/2511.23478v1/) |
| **VideoHallu** | UMD (NeurIPS 2025) | 负控制测试：物理/常识违背视频检验"真看懂 vs 靠先验" | 负样本 RL 不损害通用基准 | [PDF](http://cs.umd.edu/~jbg/docs/2025_neurips_videohallusion.pdf) |
| **DualityForge / DualityVidQA** | Tsinghua/AMAP | 反事实视频编辑造原始-编辑成对数据做对比训练 | 相对基线降幻觉 24%；DNA-Train 两阶段 SFT-RL | [2512.24271](https://arxiv.org/html/2512.24271v1/) |

**共性方法论（可复用）**：证据忠实性奖励（O&R / VAS）、反语言捷径（负控制/Text-Only 准确率）、SFT 冷启动 + RL、成对/对比数据。

## 二、2026 前沿：从"看懂视频"到"智能体化 + 空间世界模型 + 长时程记忆"

> 目标能力在迁移：2025 是"让模型看懂一段视频"，2026 是"在连续视频流里主动探索、维护世界状态、跨长时程不跑偏"。

### 2.1 智能体化视频推理（主动探索 + 会用工具）

| 论文 | 机构 | 一句话 | 关键点 | 链接 |
|---|---|---|---|---|
| **Video-DeepResearch** | USTC 等 | 从静态图像扩到连续视频流 + 开放网络探索 | 揭示两大失败模式：**modality bias**（宁可搜文本不看画面）、**参数知识泄漏**；解耦感知-探索 + 分阶段解锁工具；SFT→GRPO；35B-A3B Avg 64.0% | [2608.03979](https://arxiv.org/html/2608.03979v1) |
| **LongVideoAgent** | HKUST | 多智能体长视频：master + grounding + vision agent + RL | 用 RL 鼓励简洁高效多智能体协作 | [2512.20618](https://arxiv.org/pdf/2512.20618v1) |

> VideoDR-Bench 关键结论：**agentic 并不总优于 workflow**，收益取决于能否在长检索链里守住初始视频锚点；**goal drift / long-horizon consistency 是核心瓶颈**。

### 2.2 空间智能 / 世界模型（2026 最热、也最"跌破眼镜"的缺口）

## 三、视觉 Agent 数据（computer-use / GUI / office）——"保视觉理解 + 加 agent 能力"

> 核心命题：**在不退化视觉理解/grounding 的前提下加 agent 能力**。数据从"视频三元组"变为**三类并存**：
> ① Grounding（指令→坐标）② GUI Understanding（截图 caption/OCR/布局）③ Trajectory（多步观察-动作-可验证结果）。

### 3.1 直接研究"agent 训练会不会伤视觉/grounding"——最贴我的顾虑

| 论文 | 机构 | 一句话 | 关键结论 | 链接 |
|---|---|---|---|---|
| **GUI-Libra** ⭐ | - | 正面回答"加 agent 又不掉 grounding" | **"SFT with Long CoT Hurts GUI Grounding"**；解法 Action-aware SFT + 部分可验证 RL | [2602.22190](https://arxiv.org/html/2602.22190v2) |
| **ProCUA-SFT** | NVIDIA | 轨迹数据质量差会负迁移 | AgentNet SFT 让 UI-TARS-7B OSWorld **26.3%→8-10%**；换带前置条件验证的合成数据 →45% | [2606.17321](https://arxiv.org/html/2606.17321v1) |
| **GUI-Perturbed** | - | 域随机化揭示 grounding 系统性脆弱 | 空间关系是主要失败模式；**"Reasoning Is Not Uniformly Beneficial"** | [2604.14262](https://arxiv.org/html/2604.14262v2) |

### 3.2 完整数据 pipeline 技术报告——可当我 pipeline 对标蓝本

| 论文 | 机构 | 一句话 | 三类数据规模/设计 | 链接 |
|---|---|---|---|---|
| **ScaleCUA** ⭐ | - | 跨 6 平台三类数据并存 | Understanding 471K + Grounding 17.1M + 轨迹(15K弱语义+4K目标)；base Qwen2.5-VL；三种推理模式 | [2509.15221](https://arxiv.org/pdf/2509.15221) |

| **Mobile-Agent-v3.5 / GUI-Owl-1.5** | 阿里 | 多平台原生 GUI agent | 多设备轨迹(带CoT)+增广grounding+tool/MCP+浏览器；混合数据飞轮；OSWorld 56.5 | [2602.16855](https://arxiv.org/html/2602.16855v1) |

## 四、给我 vlm-agent 项目的三条主线小结

```text
① 视频理解数据（我在做的）：证据忠实 + 反捷径 + 难度对齐 —— 方法论已成熟，被 2025 主线反复验证
② 2026 前沿目标迁移：智能体化(modality bias/goal drift) + 空间世界模型 + 长时程记忆
   —— 我的失分诊断→靶向数据→SFT/RL 方法论不变，变的是"目标能力"
③ 视觉 Agent 数据（下一步）：understanding + grounding + trajectory 三类并存
   —— "不退化视觉"靠把 understanding/grounding 作独立数据线持续混训，不是训练时小心
   —— 我可迁移的三点：反捷径量化验收(Text-Only准确率) / 难度坍缩治理(难度在环境里) / 证据忠实质检(每步action是否被截图支持)
```
