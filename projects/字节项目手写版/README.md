# 字节项目手写版 · 目录说明

> 定位：VLM 长视频复杂推理方向，从「底层基建 → 视频获取 → 训练数据构造」三层拆开记录的手写版项目文档。
>
> 三份文档不是并列的三个项目，而是**同一条数据生产链路的三层**：下层是基建，中层调用基建获取视频，上层在获取到的视频上做 VLM 训练数据合成。

---

## 一、三层定位

```text
第 3 层  数据构造（VLM 训练数据合成）
        在已获取的视频上，合成 Caption / QA / CoT 训练数据
                    ▲  消费视频（TOS）
                    │
第 2 层  视频获取（数据生产 Pipeline）
        用基建把「数据需求」变成「合格视频 + TOS + Metadata」
                    ▲  调用检索 / 抓取能力
                    │
第 1 层  基建（自研检索与抓取平台）
        提供并发检索、URL 解析、视频抓取、TOS 转存等底层能力
```

一句话概括每层的角色：

- **基建**：提供“能搜、能抓、能存”的通用能力，本身不绑定某个具体数据需求。
- **获取**：把基建能力编排成一条「需求 → 检索 → 筛选 → 抓取 → 交付」的流水线，产出可用视频。
- **构造**：不再关心视频怎么来的，只在已交付的视频上做 Caption / QA / CoT 的数据合成。

## 三、逐层说明

### 1. 基建 —— 自研检索与抓取平台

底层能力层，被上面两层复用：

```text
├── 检索平台：多关键词并发召回，返回视频 URL + Metadata
└── Fetch 平台：解析 URL → 下载视频到本地 → 转存 TOS 链接
```

上层文档里出现的“自研检索平台”“自研 Fetch 平台”“并发抓取 + 失败重试 + TOS 转存”等，都是在调用这一层。

> 该文档已成文，聚焦“平台提供哪些能力、检索/抓取的边界、并发与状态管理”，与上层的“业务编排”区分开；部分接口与规模细节标为待确认，按真实实现补充。

### 2. 获取 —— 长视频获取 Pipeline

调用基建，把训练数据需求变成合格视频：

```text
需求定义 → Data Rubric → 候选检索（通用关键词 + Agent Query Expansion）
→ 多级预筛（标题规则 → Metadata/画质 → 抽帧 + VLM 内容质检）
→ 并发抓取 → 转码标准化 → TOS → 交付带 Metadata 的数据表
```

- 目标：500 条、30～90 分钟的实践操作类长视频（样例为化学实验操作）。
- 结果：候选召回 3000 → 筛选通过 520 → 完整采集并转存 TOS 500。
- 核心思想：Cost-aware 多级过滤（低成本规则优先、高成本 VLM 判断后置），VLM 在此充当 Data Quality Gate 而非训练对象。

**产出交给第 3 层**：带 TOS 链接的合格视频，即数据构造的统一视频输入。

### 3. 构造 —— 证据检索式数据合成 Pipeline

在已获取的视频上做 VLM 训练数据合成，参考阿里 ReWatch-R1，产出三类带时间戳的数据：

```text
Caption 合成：低帧率语义切段 → 高帧率局部描述 → 时间戳重对齐
             → 带时间戳索引的事件库 C_detail(V)
QA 合成    ：对比差异生成（C_detail vs C_sum）+ 三层过滤
             （答案核验 / 文本偏置核验 / 摘要偏置核验）
CoT 合成   ：多 Agent 协作（Reasoner 发检索指令 → Observer 在 C_detail 取证
             → Reasoner 判断或作答 → Convert 整理为带 <action>/<observation> 的 CoT）
```

- 目标：产出“必须依赖视频细节 + 多步推理”的高难 QA，以及“先检索证据再推理”的 video-grounded CoT。
- 该文档也含“检索 / 抓取”两节，但那是**复用第 1、2 层能力的简要交代**，主体和重点是数据构造。

## 四、端到端串联

```text
[基建]  检索平台 + Fetch 平台
          │  提供能力
          ▼
[获取]  需求 → 检索 → 多级筛选 → 抓取 → TOS 交付
          │  输出 500 条合格视频（TOS）
          ▼
[构造]  Caption → QA → CoT 训练数据合成
          │  输出带时间戳的 VLM 训练数据
          ▼
       下游：SFT / RLVR 训练
```
